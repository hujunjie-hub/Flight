# Flight public contracts (Schema 6.0)

Production headers for the Flight V1.9.1 public ICD/Port/Product Contract.
The normative source is `spec/02_接口契约与公共数据规范.md`
(baseline `V1.9.1-GLOBAL-AUDIT-R3`); these headers are the compilable form of
that contract and must not redefine any field, unit or semantic on their own.

## Include order

```text
base_types/contract_version.h
  -> base_types/common_base.h          (ContractHeader, time/raw services, samples, NavStateCore)
  -> product_contract/product_contract.h  (selects the product extension types)
  -> ports/control_model_types.h (NX/NU dimension types)
  -> messages/common_messages.h  (all registered messages)
  -> ports/port_types.h           (FMS/Guidance/Controller/Plant aggregates)
  -> ports/port_api.h             (Port function declarations)
messages/message_ids.h            (message type registry constants)
```

Add `middleware/contracts/` to the include path and include `"ports/port_api.h"`.
Consumers of the message registry alone include `"messages/message_ids.h"`.
Shared validation helpers live in `contract_checks/`.

## Product contract

`product_contract/product_contract.h` declares the shared data layouts and
profile ID for this build. `product_contract/abi_lock.h` holds the ABI baseline.
Developers bind implementations in the corresponding module build configuration.

## Frozen values

| Item | Value |
|---|---|
| `CONTRACT_SCHEMA_MAJOR` / `MINOR` | 6 / 0 |
| `PORT_API_REVISION` | `0x00010906` |
| `PRODUCT_CONTRACT_REVISION` | `0x00010906` |
| `PRODUCT_PROFILE_ID` | `0x00010001` |
| `ContractHeader` size | 88 bytes |

Public structures use fixed-width integers and IEEE-754 float32/double64,
natural alignment (maximum 8), no packing, no `void*` payload and no pointers
inside messages. Pointers exist only in the synchronous Port aggregates of
`port_types.h`.

## ABI lock and verification

`middleware/contracts/product_contract/abi_lock.h` is generated by
`tests/abi/abi_report.py --emit-lock`. It binds the ARM and Host
ABI hashes, the message registry SHA256 and the ContractHeader size. Do not
edit it by hand; regenerate only with an approved ICD change.

```text
python tests/abi/abi_report.py           # verify (CI gate)
python tests/abi/negative_control.py     # prove drift is detected
```

Evidence is written to `tests/abi/evidence/`. This proves the
production headers compile and keep the normative layout on the validated
toolchains; it does not replace a target firmware build, consumer
recompilation, WCET or HIL (those remain separate verification items).

## Boundaries

- Self-contained C11/C++14 headers; also usable from the existing C99
  firmware build (portable compile-time assertion fallback).
- No RT-Thread, HAL, CMSIS, Simulink or vendor includes.
- No network/Flash serialization by struct memory copy; wire formats have
  their own schemas.
- The H723 firmware must not link `plant_sim_*` / `sensor_sim_*`.
