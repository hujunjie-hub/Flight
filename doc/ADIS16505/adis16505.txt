FEATURES                                                                                                           GENERAL DESCRIPTION

Triaxial, digital gyroscope                                                                                        The ADIS16505 is a precision, miniature microelectromechanical
   ±125°/sec, ±500°/sec, ±2000°/sec dynamic range models                                                           system (MEMS) inertial measurement unit (IMU) that includes
   2.3°/hr in-run bias stability (ADIS16505-1)                                                                     a triaxial gyroscope and a triaxial accelerometer. Each inertial
   0.13°/hr angular random walk, x-axis and y-axis, 1                                                              sensor in the ADIS16505 combines with signal conditioning
      (ADIS16505-1)                                                                                                that optimizes dynamic performance. The factory calibration
   ±0.25° axis to axis misalignment error                                                                          characterizes each sensor for sensitivity, bias, alignment,
                                                                                                                   linear acceleration (gyroscope bias), and point of percussion
Triaxial, digital accelerometer, ±78.4 m/sec² dynamic range                                                        (accelerometer location). As a result, each sensor has dynamic
   26.5 m/sec² in-run bias stability (x-axis and y-axis)                                                           compensation formulas that provide accurate sensor
                                                                                                                   measurements over a broad set of conditions.
Triaxial, delta angle and delta velocity outputs
Factory calibrated sensitivity, bias, and axial alignment                                                          The ADIS16505 provides a simplified, cost effective method for
                                                                                                                   integrating accurate, multiaxis inertial sensing into industrial
   Calibration temperature range: -40°C to +85°C                                                                   systems, especially when compared with the complexity and
SPI compatible data communications                                                                                 investment associated with discrete designs. All necessary motion
Programmable operation and control                                                                                 testing and calibration are part of the production process at the
                                                                                                                   factory, greatly reducing system integration time. Tight orthogonal
   Automatic and manual bias correction controls                                                                   alignment simplifies inertial frame alignment in navigation
   Data ready indicator for synchronous data acquisition                                                           systems. The serial peripheral interface (SPI) and register
   External sync modes: direct, scaled, and output                                                                 structure provide a simple interface for data collection and
   On demand self-test of inertial sensors                                                                         configuration control.
   On demand self-test of flash memory
Single-supply operation (VDD): 3.0 V to 3.6 V                                                                      The ADIS16505 is available in a 100-ball, ball grid array (BGA)
14,700 m/sec2 mechanical shock survivability                                                                       package that is approximately 15 mm × 15 mm × 5 mm.
Operating temperature range: -40°C to +105°C
