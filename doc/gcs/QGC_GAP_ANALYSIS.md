## 2. 「固件无后端」项的分工

### A. 地面站侧即可解决（不需要改固件）

| 项 | 说明 | 现状 |
|---|---|---|
| 视频页 / 视频流 | 配置 RTSP/UDP 地址并解码，与飞控无关 | 页面保留 |
| 3D 视图 | 用地形高程 + 载具位姿渲染 | 页面保留，未验证渲染 |
| ADSB 服务器 | 地面站侧接 ADSB 接收机或网络源 | 页面保留 |
| 日志分析（Log Viewer / 图表） | 本地解析 .bin/.ulg/.tlog | 已具备 |
| 地图 / 离线地图 / 单位 / 语言 / 配色 | 本地设置 | 已汉化、已具备 |
| 任务模板、Transform、GeoFence/Rally 编辑 | 只生成标准 MAVLink 计划，固件已支持上传 | 编辑按钮待逐项验收 |
| Comm Links（UDP/串口参数） | 本地链路层 | 页面正常 |
| 参数编辑 | 参数协议固件已实现 | 已验（写入待复验） |
| 固件刷写页 | 若走 STM32CubeProgrammer CLI / DFU，可完全在 GCS 侧实现 | 目前隐藏，可做成 Flight 专用页 |
| 远程 ID 设置页 | 页面只做配置，**广播**才需要固件 | 页面保留 |

### B. 必须 Flight 固件适配（方案，本轮不动）

| # | 能力 | MAVLink | 固件侧方案要点 | 工作量 |
|---|---|---|---|---|
| B1 | 前往指定点 | `DO_REPOSITION` | guidance 增加「外部位置目标」入口，映射为 PositionTarget 走现有位置环/MPC；需限幅与超时 | 中 |
| B2 | 改高度 | `DO_CHANGE_ALTITUDE` | 同上，改参考高度并保持水平位置 | 小 |
| B3 | 改速度 | `DO_CHANGE_SPEED` | 改 MPC 参考速度上限与轨迹时间参数 | 小 |
| B4 | 盘旋 | `DO_ORBIT` | guidance 生成圆周轨迹（或复用轨迹规划） | 中 |
| B5 | 兴趣点 ROI | `DO_SET_ROI` | 机头指向目标点，需与航向控制/任务 yaw 策略统一 | 中 |
| B6 | 改航向 | `CONDITION_YAW` | 定点模式下的 yaw 目标通道 | 小 |
| B7 | 指定坐标设 Home | `DO_SET_HOME`(param1=0) | 现在只接受 param1=1；放开坐标写入并做地理校验 | 小 |
| B8 | 紧急停 / 强制解锁 / 复飞 | 多命令 | 安全相关，需要独立的安全状态机与审计日志 | 大 |
| B9 | 清空任务 | `MISSION_CLEAR_ALL` | FMS 要求 mission_id+epoch；可在 DISARMED+IDLE 放宽，或由 SIL 补全身份 | 小 |
| B10 | 任务项相机/云台 | 相机协议 | 需要相机组件与 MAVLink 相机代理 | 大 |
| B11 | 摇杆（MANUAL_CONTROL） | `MANUAL_CONTROL` | 手动控制通道 + 接管判据 | 中 |
| B12 | 传感器校准 / 电机测试 | `PREFLIGHT_CALIBRATION`、`DO_MOTOR_TEST` | 校准流程与测试模式 | 大 |
| B13 | Remote ID 广播 | `OPEN_DRONE_ID_*` | 需要 UAS ID 配置与广播周期 | 中 |
| B14 | NTRIP/RTK | `GPS_RTCM_DATA` | 把 RTCM 注入 UM982（现有只有 unicore ASCII 配置通道） | 中 |

> 建议顺序：B7 → B9 → B2/B3/B6（小改动、收益直接）→ B1/B4/B5（制导侧）→ B8/B10/B11/B12/B13/B14。

## 3. 结论

- 「固件不支持」的按钮里，**约一半其实是地面站侧问题**（视频、3D、ADSB、日志、地图、任务模板、刷写页、链路、远程 ID 配置），不需要固件配合。
- 真正需要改固件的是 **B1–B14**，其中 B7/B9 改动最小、建议优先。
- 「已接通待验收」的 12 项属于纯验收工作，不涉及新代码。
