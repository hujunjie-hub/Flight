# QGC 参数与校准

地面站的参数导入差异预览、传感器分步提示和遥控行程确认参考本机 LGroundControl。
按钮级状态见 [QGC 按钮矩阵](QGC_BUTTON_MATRIX.md)。

## 1. 参数链路

### 1.1 唯一参数目录

`config/` 下的五份 YAML 由
[`generate_ground_config.py`](../../tools/generate_ground_config.py) 生成：

| 产物 | 消费方 |
|---|---|
| `middleware/protocol/mavlink/parameters/ground_parameters.h` | 固件 `parameter_store` |
| `ground_parameters.json` | QGC 元数据生成器、审计 |
| `ground_parameters.md` | 人工核对 |

固件内部目录 **109 项**：70 项控制器参数 + 39 项校准参数。
但 MAVLink / QGC 参数页只暴露 **48 项实际调参核心参数**：
47 项 `CTL_*` + `VEH_MASS`。SIL 额外暴露 `SIM_TLM_HZ`，因此 SIL 下是
**49 项**；H723 是 **48 项**。

以下参数保留在固件内部，不进入 QGC 参数页/参数文件：

| 类别 | 原因 |
|---|---|
| `VEH_IXX/IYY/IZZ/IXY/IXZ/IYZ` | 机体惯量，属于模型识别/重编译，不是日常调参 |
| `VEH_M0..M3_X/Y/Z/YAW` | 电机安装位置和反扭矩系数，属于机型几何 |
| `CAL_*`、`RC_*` | 由 首次使用按陀螺仪、加速度计、磁罗盘、水平校准、地面气压、遥控器的顺序操作。
加速度计完成后，地面站开放磁罗盘和水平校准。六面采集依次提示正放、倒放、
机头朝上、机头朝下、左侧朝下和右侧朝下。遥控行程采满后，把方向摇杆回中，
油门降到底，再确认保存校准结果。

开始使用 `MAV_CMD_PREFLIGHT_CALIBRATION` (241)。水平校准使用 param5=2，
六面校准使用 param5=1。`MAV_CMD_USER_2` (31011) 的 param2 为 1 时采集
param1 指定的当前面，2 为取消，3 为确认遥控行程。固件的 `FCAL` 状态回报
包含校准项、状态、已采集面和进度，界面按回报更新。

| 校准 | 为什么需要 | 固件输入 | 输出参数 |
|---|---|---|---|
| 陀螺零偏 | 静止时角速度不为零会直接积分成姿态漂移 | 1.5 s IMU 静止样本，检查方差 | `CAL_GYRO_X/Y/Z`、`CAL_GYRO_OK` |
| 加速度六面 | 零偏和比例误差会造成水平误判与高度/姿态耦合 | 六个面各 ≥100 个样本，面方向校验 | `CAL_ACC_X/Y/Z`、`CAL_ACC_SX/SY/SZ`、`CAL_ACC_OK` |
| 磁罗盘硬/软铁 | 机载电流、磁体、结构件会造成椭球畸变 | 缓慢绕三轴旋转，检查覆盖和样本数 | `CAL_MAG_X/Y/Z`、`CAL_MAG_SX/SY/SZ`、`CAL_MAG_OK` |
| 水平姿态 | 安装倾斜会让“水平”读数不为零 | 1 s 水平静止加速度 | `CAL_LVL_ROLL/PITCH`、`CAL_LVL_OK` |
| 气压基准 | 气压高度需要当地基准 | 1 s 静止气压 | `CAL_BARO_P0` |
| 遥控行程 | 不同遥控器/ELRS 的端点与中位不同 | CRSF 前四通道端点及确认时的实际中位 | `RC_MIN_n`、`RC_MAX_n`、`RC_TRIM_n`、`RC_CAL_OK` |

不再为本机配置的项：

| 项 | 原因 |
|---|---|
| 空速 | 本机没有空速管，UM982 只提供 GNSS |
| 电池电压/电流 | PMU 没有可信的电池采样链路；SYS_STATUS 保持 unknown |
| 电调/电机测试 | H723 为 `BENCH_INHIBIT`，物理输出能力 mask 为 0，测试按钮必然被安全状态拒绝 |
| 云台/相机 | 没有相机组件 |

### 2.1 重复校准

校准服务测量的是“当前校准已生效后的残差”，runtime 把残差 **累加** 到已有
参数（比例项相乘），因此重复校准会收敛而不是把上一次结果覆盖掉。失败的
校准不会清除已有的 `*_OK` 标志。

### 2.2 磁罗盘与遥控的当前边界

- **磁罗盘**：`MAG_AIDING` 在实机镜像仍为 DISABLED，校准值只改善诊断和后续
  启用的准备度；不要据此宣称已具备磁航向融合。
- **遥控**：ELRS 已实现 CRSF 解码、`RC_CHANNELS` 遥测和通道监视；FMS 的
  遥控飞行权限仍未接入（操作权仍来自 GCS 指令）。`RC_CAL_OK` 只表示行程
  已记录，不表示可以用遥控器接管飞行。
